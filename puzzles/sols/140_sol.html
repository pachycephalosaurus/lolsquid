This is one of the coolest puzzles I have ever seen. Let's dig in to my writeup:

The first thing to notice is that this is actually nine puzzles and a meta (the latter of which is obvious, but the distinctions between puzzles can be confusing.) Divided with line breaks, the puzzle would look like this:

1. 🐾❄🥅#📌♠💦255879
2. ⠗⠕⠞⠼⠁⠊⠉:⠺⠠⠰⠶⠮
3. ∞WᒧO3>H∽UO)Z⊢
4. せம佛أر➪ᓭܜ⚡ﺪトΛí
5. ĆẸİĿMṈOṖ$ŦŪVY
6. A hot new vow
7. ⊔N⌶ⅽ✜ዐᛊfirsts
8. 🐌🌮🚇✒🔑🛑🐣➖💅☄📂🎹🎩
9. V𝙸२-ƧΞ⊕ꘜ⊞।Ʌ𝟾⎕
META:…|#/|@…:@**¢#1¢1:/

With that out of the way, let's go puzzle by puzzle:

1: 🐾❄🥅#📌♠💦255879


The mechanic here is a 3x3 crossword, clued by the # character. The first three emoji are the across clues, and the second three are the down clues. When properly filled out, the crossword looks like this:

PAW
ICE
NET

With the completed crossword, we can use the given numbers (255879) to select letters as if the grid were a phone keypad. With the top left corner corresponding to 1 and the bottom right to 9, we can extract ACCENT as our first answer!

2. ⠗⠕⠞⠼⠁⠊⠉:⠺⠠⠰⠶⠮

This is a puzzle that's almost entirely in Braille, except for that sneaky colon! The text, when translated from Braille, reads rot193: wGgthe (the weird, repeated G comes from the ⠠ Braille character, indicating uppercase. This will quickly be demonstrated as irrelevant.)

rot193 would not be a valid shift, as it would depend on a 193-character alphabet (usually only achievable with an extended ASCII characterset, which leads to very ugly answers). Instead, rot193 is to be interpreted as rot180 + rot13, the former corresponding to a 180º rotation of the Braille following the colon. Doing this converts ⠺⠠⠰⠶⠮ to ⠝⠛⠃⠁⠗, or NGBAR. After applying the rot13, the answer ATONE is revealed.

3. ∞WᒧO3>H∽UO)Z⊢

This one is fairly simple: just rotate each character 90º clockwise to get:
8ΣLOω VISCOUNT
with the first word to be read as BELOW. The British nobility class BELOW the VISCOUNT is the BARON, solving puzzle 3.

4. せம佛أر➪ᓭܜ⚡ﺪトΛí

This puzzle, like puzzle 2, is split into components before and after the delimeter (in this case, ➪). The symbols to the left of the arrow, in order, are:
  • せ - Japanese kana SE
  • ம - Tamil MA
  • 佛 - Mandarin FÓ
  • أر - Arabic 'A.RA
When pronounced in English, this can be read as SEMAPHORE, indicating that the characters to the right of the arrow are to rbe interpreted as if they were in semaphore. With the first character ᓭ interpreted as C, this gives COLOGNE as the fourth answer. (NOTE: ﺪ is likely the most difficult character to properly interpret due to differences in font rendering, but leaving it blank and solving the rest should make the answer obvious).

5. ĆẸİĿMṈOṖ$ŦŪVY

This is an anagram puzzle with some Morse code imbued into it. Unscrambling the letters (Nutrimatic times out, but Qat saves the day!) gives CONSUMPTIVELY, or ĆOṈ$ŪMṖŦİVẸĿY with the accent markings included. Each letter has either one extra dot, one extra line, or is plain, and these correspond to dots, dashes, and slashes. The written out morse code translation of the word is - / --- / .-. / .. /, which translates to TORI. Combining this with the previous result gives TORI, CONSUMPTIVELY, a crossword clue that solves to DONUTS (TORI being the plural of TORUS).

6. A hot new vow

This is a cryptic that solves to OATH. The definition is "VOW" and the wordplay is "A HOT, NEW" or a scrambling of "AHOT" to "OATH". I'm not sure how I feel about this one.

7. ⊔N⌶ⅽ✜ዐᛊfirsts

This can be read as "UNICODE FIRSTS", implying we want the first character of the Unicode name (not code!) of the characters:
  • ⊔ - u+2294 Square Cup
  • N - u+004E Latin Capital N
  • ⌶ - u+2336 APL Functional Symbol I-Beam
  • ⅽ - u+217D Small Roman Number One Hundred
  • ✜ - u+271C Heavy Open Centre Cross
  • ዐ - u+12D0 Ethipoic Syllable Pharyngeal A
  • ᛊ - u+16CA Runic Letter Solwilo
The first letter of each character name spells out SLASHER, solving puzzle 7.

8. 🐌🌮🚇✒🔑🛑🐣➖💅☄📂🎹🎩

This is an emoji rebus puzzle with another delimiter (➖). The first emoji are:
SNAIL TACO METRO PEN KEY STOP HATCH
and the second emoji are
NAIL COMET OPEN KEYS TOPHAT.

Subtracting the second emoji from the first leaves the letters S---- TA-- ---R- --- ---- ---CH, or STARCH as our next answer.

9. V𝙸२-ƧΞ⊕ꘜ⊞।Ʌ𝟾⎕

Almost done! This last puzzle uses the XOR symbol (⊕) to denote the ... XOR-ing(?) ... of the two strings before and after it. The XOR operator only takes parts present in one of the symbols (in other words, any common areas between the two symbols are deleted). Doing this with V and ꘜ gives T (for example), and going through all of the symbols gives:
  • V ⊕ ꘜ -> T
  • 𝙸 ⊕ ⊞ -> H
  • २ ⊕ । -> R
  • - ⊕ Ʌ -> A
  • Ƨ ⊕ 𝟾 -> S
  • Ξ ⊕ ⎕ -> H
with the final answer being THRASH.

META:…|#/|@…:@**¢#1¢1:/

Meta time! To recap, our answers are:
ACCENT, ATONE, BARON, COLOGNE, DONUTS, OATH, SLASHER, STARCH, and THRASH (in order)
The meta consists of 9 (hmmm) different symbols, each repeated twice (hmmm). Identifying these symbols (in a convenient order), we have ¢ (CENT), 1 (ONE), | (BAR), : (COLON), ... (DOTS), @ (AT), / (SLASH), * (STAR), and # (HASH). Astute readers may have noticed the similarities between STAR and STARCH, as well as BAR and BARON. This is the link between answer and meta; SYMBOL = ANSWER - 2 LETTERS , one for each occurrence! How sweet! Subtracting the answers gives:

  • …: dots -> DONUTS - NU
  • |: bar -> BARON - ON
  • #: hash -> THRASH - TR
  • /: slash -> SLASHER - ER
  • |: bar -> BARONS - ON
  • @: at -> OATH - OH
  • …: dots -> DONUTS - NU
  • :: colon -> COLOGNE - GE
  • @: at -> OATH - OH
  • *: star -> STARCH - CH
  • *: star -> STARCH - CH
  • ¢: cent -> ACCENT - AC
  • #: hash -> THRASH - TR
  • 1: one -> ATONE - AT
  • ¢: cent -> ACCENT - AC
  • 1: one -> ATONE - AT
  • :: colon -> COLOGNE - GE
  • /: slash -> SLASHER - ER


Or, in proper order,

  • … - N
  • | - O
  • # - T
  • / - E
  • | - N
  • @ - O
  • … - U
  • : - G
  • @ - H
  • * - C
  • * - H
  • ¢ - A
  • # - R
  • 1 - A
  • ¢ - C
  • 1 - T
  • : - E
  • / - R
with our final final answer being NOT ENOUGH CHARACTER, which is a valid complaint against Twitter!
